## Task

Build a simple Habit Tracker application.

### Required Features

#### 1\. Cross-platform app

The app should run on:

- iOS
- Android
- Web

Use `react-native`.

---

#### 2.1 Initial Registration Screen

When the app launches for the first time, display a registration form.

Users should provide:

- Full name
- Email address
- Password
- Confirm password
- Sex
- Birth Date

#### 2.2 Login Screen

When the app launches after a while, display a login form.

Users should provide:

- Email address
- Password

#### 2.3 Habit management

Users can:

- Create a habit
- Mark a habit as completed for today
- Delete a habit
- View completion streak

---

#### 3\. AI-powered feature

Add one AI feature that improves the user experience.

Examples:

- Generate habit suggestions based on a goal
- Rewrite habits to be more actionable
- Analyze habit history and provide recommendations
- Any other idea you think creates value

You may use any LLM provider.

---

#### 4\. Offline support

The app should remain functional without network connectivity.

Local storage is sufficient.
